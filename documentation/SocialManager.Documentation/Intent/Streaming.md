# Streaming

## Intent overview
The `Streaming` intent is designed to facilitate interactions related to live streaming platforms and online broadcast communities. This intent can be used to manage streaming.

The feature will allow features such as managing stream settings and handling viewer interactions, such as bans, timeouts and the like.

It also combines multiple platforms into a single interface, being easier to use for streamers that broadcast on multiple platforms.
